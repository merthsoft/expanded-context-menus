# Expanded Context Menus

<!-- merthsoft-download -->
## Download

[Download expanded-context-menus.zip](https://merthsoft.com/RimWorld/expanded-context-menus.zip) — RimWorld 1.7 release.

The archive includes older supported version folders where available. Extract the mod folder into RimWorld's `Mods` directory.
<!-- /merthsoft-download -->

Adds expanded context menus when you right click on an object.

Works with AllowTool's right-click menus, but you should disable the watermark for AllowTool in the mod options.

Works with Achtung's force commands

Works with Reverse Commands' reverse commands
